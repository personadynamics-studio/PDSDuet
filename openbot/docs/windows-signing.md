# Windows desktop signing

The GitHub signing workflow and its regression suite are no longer included in this checkout.
The remaining signing sources are `desktop/scripts/sign-windows.ps1`,
`desktop/scripts/verify-windows-signatures.ps1`, and the desktop signing configuration.
Review those sources for signing changes; running packaging or signing requires explicit authorization.

See [desktop build versions](releasing.md#desktop-build-versions) for the version tooling.
